# camera-app

Persönlicher Fork von [Open Camera](https://opencamera.org.uk/) für das Google Pixel 9 Pro,
erweitert um eigene Features (360°-Foto-Stitching, Clip-Tagebuch-Modus, Dual-Kamera mit
unabhängigem Zoom, u. a.).

Nur für den persönlichen Gebrauch gedacht – kein Release, kein Play-Store-Eintrag geplant.

Alle Details, offene Fragen und der Projektstand: [`docs/SPEC.md`](docs/SPEC.md)

## Basis

Diese App basiert auf dem Quellcode von Open Camera (SourceForge,
`https://git.code.sf.net/p/opencamera/code`), lizenziert unter der GNU General Public
License v3 (siehe [`gpl-3.0.txt`](gpl-3.0.txt)). Diese Lizenz gilt entsprechend auch für
diesen Fork.
